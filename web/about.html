Interactive N-body orbital mechanics, learning tools, and the first step toward a C++/AI space simulation engine.
Open Simulator Current System JSON

What It Does

Runs a 2D Newtonian gravity sandbox with editable bodies, orbit initialization, trails, diagnostics, warnings, and data export.

Physics Stack

Pure Python reference engine, Velocity-Verlet integration, AU/year/solar-mass units, energy drift, angular momentum drift, and center-of-mass diagnostics.

Roadmap

Next comes the C++ physics engine, Python bindings, PyTorch experiments, and a full React/Three.js web platform.
